# GovGuard: AI-Powered Public Infrastructure Integrity Ledger

GovGuard is an AI transparency tool to monitor public infrastructure construction and prevent corruption and substandard material usage during execution.

## Key Features
- Real-Time AI Audits using Google Gemini.
- Automated Compliance Scoring and Risk Assessment.
- Official Municipal Audit Reports and Directives.

## Tech Stack
- Streamlit (Python)
- Google AI Studio (Gemini 2.5 Flash)
- GitHub
